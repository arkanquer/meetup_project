# Meetup Project

A Django-based web application for managing meetups, event proposals, and user interactions.

## Features

- User authentication and personal profiles
- Creating and managing event proposals
- Joining events through applications
- Friendship requests and connections
- Filtering active and closed proposals
- Django ORM for database interactions

## Tech Stack

- Python
- Django
- HTML
- Django Templates
- Django ORM

## Getting Started

Clone the repository:

```bash
git clone https://github.com/arkanquer/meetup_project.git
cd meetup_project
```

Create a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies and apply migrations:

```bash
pip install django
python manage.py migrate
```

Start the development server:

```bash
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.
